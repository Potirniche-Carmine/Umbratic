# Contributing

Report reproducible bugs through [GitHub Issues](https://github.com/Potirniche-Carmine/Umbratic/issues). Include your OS, app version, steps, and expected behavior. Keep credentials and private content out of reports.

Follow [README.md](README.md) for setup and read the nearest `AGENTS.md` before editing. Keep changes focused. Run focused checks and `npm run test:all`, then open a pull request explaining the change and verification. Include screenshots for visible UI changes.

Keep dependency versions and lockfiles pinned. Dependency changes must pass `npm run supply-chain:check`.

Report security vulnerabilities through [GitHub private vulnerability reporting](https://github.com/Potirniche-Carmine/Umbratic/security/advisories/new).
