# Security

Report suspected vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/Potirniche-Carmine/Umbratic/security/advisories/new).

Include the Umbratic version, operating system, steps to reproduce and potential impact. Do not include credentials, private prompts or customer data.

The [runtime advisory review](docs/reference/runtime-security.md) records reviewed bundled dependencies, source patches and qualification limits.
