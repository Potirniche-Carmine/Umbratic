Umbratic final logo assets

All files are transparent PNGs.

Primary assets:
- umbratic-full-horizontal-transparent.png: full horizontal logo for website header/navigation.
- umbratic-stacked-transparent.png: stacked mark + wordmark for square/centered placements.
- umbratic-icon-transparent.png: 1024x1024 icon on a transparent square canvas.
- umbratic-icon-no-padding-transparent.png: icon-only mark with no square canvas padding.
- favicon-16x16.png, favicon-32x32.png, favicon-48x48.png, favicon-64x64.png, favicon-128x128.png, favicon-192x192.png: favicon/app icon sizes.

Style notes:
- Monochrome black/charcoal identity with a very subtle smooth gray-to-black gradient.
- Wordmark uses Inter-style typography, matching the final concept board direction.
- These are polished transparent raster PNG exports. They are not hand-built vector SVG files.

Additional website files:
- favicon.ico: multi-size ICO for browser favicon use.
- apple-touch-icon-180x180.png: iOS home-screen icon size.
- web-app-icon-192x192.png and web-app-icon-512x512.png: common web manifest icon sizes.
